# Office Orcs Survey

A simple React quiz app with:
- Start screen
- 5-question wizard flow (one question per screen)
- Progress indicator
- Final results screen
- Mobile-responsive layout

## Project Structure

- `index.html` - App entry point
- `styles.css` - All styles
- `questions.js` - Quiz questions and result text logic
- `app.js` - React app logic and rendering

## Run Locally (npm)

From the project folder, run:

```bash
npm install
npm start
```

Then open:

- `http://localhost:3000`

Press `Ctrl + C` in the terminal to stop the server.

## Notes

- The app uses React and ReactDOM from CDN scripts in `index.html`.
- Internet access is required to load CDN resources (React, ReactDOM, Babel, and Google Fonts).
